# Electric-field interaction

The rigid- and vibrational-rotor models use the same length-gauge interaction.
The molecular response properties are body-fixed quantities evaluated with the
internuclear axis along the body-fixed $z$ direction. The applied field is
linearly polarized along the laboratory-fixed $z$ direction, and $\theta$ is the angle
between the two axes.

## Interaction Hamiltonian

Through first hyperpolarizability order, the interaction used by the package is

$$V(R,\theta,t)=-d(R)E(t)\cos\theta-\frac{E(t)^2}{2}\left[\alpha_\perp(R)+\left(\alpha_\parallel(R)-\alpha_\perp(R)\right)\cos^2\theta\right]-\frac{E(t)^3}{6}\left[\beta_\parallel(R)\cos^3\theta+3\beta_\perp(R)\sin^2\theta\cos\theta\right].$$

Here $d$ is the permanent dipole, $\alpha$ is the polarizability, and $\beta$ is the
first hyperpolarizability. For a rigid rotor these quantities are scalars at
the fixed bond length; for a vibrational rotor they are functions of $R$.
The hyperpolarizabilities are optional and are set to zero when omitted.

The permanent-dipole and first-hyperpolarizability terms are odd under
$\cos\theta\mapsto-\cos\theta$, so they couple even and odd angular momenta.
The polarizability term preserves angular parity. Consequently,
`angular_sector="auto"` can retain only one parity sector when all odd-rank
interactions vanish, but selects the full angular basis otherwise.

For a homonuclear molecule, an omitted permanent dipole is interpreted as zero.
A heteronuclear molecule requires a dipole value or curve. Supplying `dipole=0`
explicitly is useful when constructing a model that deliberately neglects the
permanent-dipole interaction.

## Supplying fields

The `fields` argument accepts one callable or an iterable of callables. Each
callable receives a time in atomic units and must return one finite real scalar.
Multiple fields are added before the interaction is evaluated:

$$E(t)=\sum_k E_k(t).$$

This detail matters for multicolor fields: the quadratic and cubic terms contain
the cross terms generated by $E(t)^2$ and $E(t)^3$. They are not evaluated as
independent interactions for each pulse.

Both rotor interfaces support the length gauge only. A field object with a
`gauge` attribute must therefore have `gauge="length"`. A plain callable without
that attribute is assumed to return a length-gauge electric field.

Pulse implementations can be imported from
[`electromagnetic-fields`](https://github.com/HyQD/electromagnetic-fields):

```python
from electromagnetic_fields.dipole_fields import SineSquareLaser

pulse = SineSquareLaser(
    E0=0.01,
    omega=0.057,
    ncycles=4,
    phase=0.0,
    gauge="length",
)
```

`SineSquareLaser` and compact trigonometric-Gaussian pulses have finite time
support. A true `GaussianLaser` has open support and therefore requires an
explicit `final_time`. If every field has finite `time_support`, `final_time`
defaults to the latest support endpoint. Field-free propagation also requires
an explicit `final_time`.

The Gaussian pulse uses a sine carrier. Thus `phase=np.pi / 2` produces a cosine
carrier at the pulse center.

## Conversion to atomic units

The interfaces expect electric-field amplitudes, angular frequencies, and times
in atomic units. With $E_\mathrm{a}$, $t_\mathrm{a}$, and $E_\mathrm{h}$ denoting the
atomic units of electric field, time, and energy,

$$E_0\,[\mathrm{a.u.}]=\frac{E_0\,[\mathrm{V/m}]}{E_\mathrm{a}},\qquad \omega\,[\mathrm{a.u.}]=\omega\,[\mathrm{s}^{-1}]t_\mathrm{a},\qquad t\,[\mathrm{a.u.}]=\frac{t\,[\mathrm{s}]}{t_\mathrm{a}}.$$

For a wavelength λ in SI units, the angular frequency is

$$\omega\,[\mathrm{a.u.}]=\frac{2\pi c}{\lambda}t_\mathrm{a}.$$

The standard cycle-averaged intensity of a monochromatic field with peak
amplitude $E_0$ is

$$I=\frac{1}{2}c\epsilon_0E_0^2.$$

The examples [`rigid_rotor_LiH_single_color.py`](../examples/rigid_rotor_LiH_single_color.py)
and [`rigid_rotor_LiH_two_color.py`](../examples/rigid_rotor_LiH_two_color.py)
show the conversions alongside the physical parameters.
